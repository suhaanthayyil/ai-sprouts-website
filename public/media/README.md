# Approved media goes here

Organize consent-confirmed images by event and day, for example:

```text
media/
  workshops/
    fort-mill-library-ai-lab/
      day-1/
      day-2/
```

After adding an image, connect its public path in `content/site-data.ts`, add meaningful alt text, and set `photoConsent` to `confirmed` only when permission is documented.
